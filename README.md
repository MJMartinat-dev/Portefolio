# Portfolio

Portfolio de Marie-Jeanne Martinat, ingénieure géomaticienne-programmeuse : applications cartographiques, données territoriales et projets environnementaux.

Version en ligne : [mjmartinat-dev.github.io/Portefolio/](https://mjmartinat-dev.github.io/Portefolio/)

## Réalisations

| Projet | Cadre | Outils | Code ou démonstration |
| --- | --- | --- | --- |
| OLD50m | DDT de la Drôme, 2023–2025, co-conception | SQL, PostgreSQL, PostGIS | [Forge du ministère](https://gitlab-forge.din.developpement-durable.gouv.fr/pub/dd/ddt-26-public/old50m) |
| cartOLD | DDT de la Drôme, 2025 | R, Shiny, Leaflet, sf | [Forge du ministère](https://gitlab-forge.din.developpement-durable.gouv.fr/pub/dd/ddt-26-public/cartold), [application en ligne](https://ssm-ecologie.shinyapps.io/cartOLD/) |
| BSécheresse | DDT de la Drôme, 2023–2025 | R, R Markdown, dplyr, sf, tmap | [Dépôt GitHub](https://github.com/MJMartinat-dev/Projet/tree/main/BSecheresse) |
| TerraObs26 | DDT de la Drôme, 2022–2023 | R, R Shiny | Présentation dans le portfolio |
| Priorisation des PPRN | DREAL Bourgogne-Franche-Comté, 2021–2022 | QGIS, ModelBuilder | Projet confidentiel |
| Atlas mellifères | Mellisphera, 2018–2019 | Données floristiques, Excel | Présentation dans le portfolio |
| Suivi du Lynx et du Tétras-lyre | Fédération des chasseurs de Haute-Savoie, 2018–2019 | Piégeage photographique, cartographie | Présentation dans le portfolio |

Le code d’OLD50m est distribué sous licence GNU GPL v3. Les projets sont détaillés sur la page [Projets réalisés](https://latelierdesreperes.fr/projets.html) de L’Atelier des Repères.

## Contenu du dépôt

- `index.html` : le portfolio, en un seul fichier ; les images et les polices y sont intégrées.
- `sitemap.xml` : plan du site destiné aux moteurs de recherche.
- `googleb40fee04ca112d9d.html` : fichier de validation pour Google Search Console.
- `.github/workflows/static.yml` : publication automatique sur GitHub Pages à chaque envoi sur la branche `main`.
